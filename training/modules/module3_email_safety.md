## Email Security Basics

Email is essential for business but also the #1 attack vector for cybercriminals.

**Statistics:**
- 94% of malware is delivered via email
- Average office worker receives 121 emails per day
- 1 in 99 emails is a phishing attack

---

## Email Safety Checklist

### Before Sending Email

- [ ] Is email the appropriate method?
- [ ] Have I double-checked recipients?
- [ ] Is sensitive data encrypted?
- [ ] Have I removed unnecessary attachments?
- [ ] Is the subject line clear and appropriate?

### Before Opening Email

- [ ] Do I recognize the sender?
- [ ] Was I expecting this email?
- [ ] Does the subject line make sense?
- [ ] Are there red flags? (urgency, fear, poor grammar)

### Before Clicking Links

- [ ] Did I hover to check the actual URL?
- [ ] Does the domain match the sender?
- [ ] Am I expecting this link?
- [ ] Can I navigate directly instead of clicking?

### Before Opening Attachments

- [ ] Was I expecting this attachment?
- [ ] Is the file type safe? (avoid .exe, .zip, .scr)
- [ ] Have I scanned with antivirus?
- [ ] Can I verify with the sender?

## Best Practices

### 1. Verify Before Trusting

**Always verify:**
- Unexpected attachments
- Requests for sensitive information
- Unusual requests from known contacts
- Financial transactions

**How to verify:**
- Call the sender (don't use contact info from suspicious email)
- Check with supervisor
- Use official company channels
- Look for verification codes/numbers

### 2. Think Before You Click

**Before clicking any link:**

1. **Hover** to see actual destination
2. **Check** the full URL (not just the beginning)
3. **Verify** it matches the expected domain
4. **Navigate directly** when possible

**Example:**
```
Safe:    https://amazon.com/orders
Unsafe:  https://amazon.com.phishing-site.ru
Unsafe:  http://amaz0n.com/verify-account
```

**Better approach:** Type `amazon.com` directly into your browser

### 3. Use Strong Authentication

**Multi-Factor Authentication (MFA):**
- Something you know (password)
- Something you have (phone, token)
- Something you are (fingerprint)

**Enable MFA everywhere:**
- Work email
- Banking
- Social media
- Cloud storage
- Any account with sensitive data

**Why it matters:**
Even if your password is stolen, MFA blocks 99.9% of automated attacks.

### 4. Create Strong Passwords

**Good password characteristics:**
- At least 12 characters
- Mix of uppercase, lowercase, numbers, symbols
- No personal information
- Unique for each account

**Password Manager Benefits:**
- Generates strong, random passwords
- Stores them securely
- Auto-fills login forms
- One master password to remember

**Examples:**
```
❌ Weak:     password123
❌ Weak:     Company2025
✅ Strong:   kT9#mP2$vL6&nQ4!
✅ Strong:   Correct-Horse-Battery-Staple-2025!
```

### 5. Keep Software Updated

**Why updates matter:**
- Fix security vulnerabilities
- Patch known exploits
- Improve protection

**What to update:**
- Operating system
- Email client
- Web browsers
- Antivirus software
- All applications

**Enable automatic updates** when possible

## Handling Different Email Types

### Legitimate Business Email

**Indicators:**
✅ From known sender/domain
✅ Expected communication
✅ Professional formatting
✅ Reasonable requests
✅ No pressure tactics

**Best practices:**
- Verify important requests
- Use secure methods for sensitive data
- Keep communications professional
- Archive important emails

### Suspicious Email

**Indicators:**
⚠️ Unknown sender
⚠️ Unexpected content
⚠️ Red flags (urgency, threats)
⚠️ Requests sensitive information
⚠️ Poor grammar/formatting

**Actions:**
1. Don't click links or attachments
2. Don't reply
3. Report to IT Security
4. Delete from inbox

### Compromised Account Email

**Indicators:**
⚠️ From colleague but unusual content
⚠️ Poor grammar (unusual for that person)
⚠️ Unexpected requests
⚠️ Sent at odd hours

**Actions:**
1. Contact person through different channel
2. Report to IT Security
3. Don't click or respond
4. Warn others if widespread

## Email Attachments

### Safe File Types

Generally safe (but still verify sender):
- `.pdf` (if from trusted source)
- `.txt`
- `.jpg`, `.png`, `.gif` (images)
- `.doc`, `.docx` (Word documents)
- `.xls`, `.xlsx` (Excel spreadsheets)

### Dangerous File Types

**High risk:**
- `.exe` (executable programs)
- `.scr` (screensavers - actually executables)
- `.bat`, `.cmd` (batch files)
- `.vbs`, `.js` (scripts)
- `.zip`, `.rar` (compressed files - can hide malware)

**Be cautious:**
- `.doc`, `.docx` with macros
- `.pdf` from unknown sources
- Double extensions (`.pdf.exe`)

### Attachment Safety

**Before opening:**
1. Scan with antivirus
2. Verify sender legitimacy
3. Check file extension
4. Confirm you're expecting it

**If suspicious:**
- Don't open
- Contact sender separately
- Report to IT Security
- Delete email

## Mobile Email Safety

### Additional Risks on Mobile

- Smaller screens make verification harder
- Touch interfaces increase accidental clicks
- Public WiFi exposure
- Lost/stolen devices

### Mobile Best Practices

**Before using email on mobile:**
- [ ] Enable device encryption
- [ ] Use strong device passcode
- [ ] Enable remote wipe capability
- [ ] Install security software
- [ ] Enable auto-lock

**When reading email on mobile:**
- Be extra careful with links (harder to verify)
- Avoid sensitive tasks on public WiFi
- Don't access confidential data in public
- Report lost devices immediately

## Reporting Suspicious Emails

### What to Report

**Report these immediately:**
- Phishing attempts
- Malware/virus warnings
- Suspicious attachments
- Requests for credentials
- CEO fraud attempts
- Any email that seems "off"

### How to Report

**Method 1: Forward to Security**
1. Forward email to: security@company.com
2. Include full headers
3. Don't modify the email
4. Add brief note on why it's suspicious

**Method 2: Use Report Button**
Many email clients have "Report Phishing" or "Report Spam" buttons

**Method 3: Call IT Security**
For urgent situations: (555) 999-7777

### What Happens Next

1. Security team investigates
2. Threat is identified
3. Other employees are warned if needed
4. You receive confirmation
5. Threat is blocked organization-wide

**Your report helps protect everyone!**

## Common Mistakes to Avoid

### ❌ Assuming Trust

**Mistake:** "It came from a colleague, so it must be safe"

**Reality:** Accounts get compromised. Always verify unexpected requests.

### ❌ Clicking Too Quickly

**Mistake:** Clicking links without checking

**Reality:** One click can compromise your account or install malware.

### ❌ Ignoring Red Flags

**Mistake:** "The grammar is bad, but I'll click anyway"

**Reality:** Red flags are warnings. Pay attention to them.

### ❌ Not Reporting

**Mistake:** "I'm not sure if it's suspicious, so I won't report it"

**Reality:** Better to report and be wrong than ignore a real threat.

### ❌ Reusing Passwords

**Mistake:** Using same password everywhere

**Reality:** One breach compromises all accounts.
